# hr_interview_agent Flow

This project defines a declarative CrewAI Flow in `src/hr_interview_agent/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/hr_interview_agent/flow.yaml` to change the flow. Add reusable crews under `src/hr_interview_agent/crews/`, custom Python tools under `src/hr_interview_agent/tools/`, and shared knowledge files under `src/hr_interview_agent/knowledge/`.
