# Approved Edge-Case Answers (Team Knowledge)

These are approved, customer-safe answers for edge cases, curated by support
leads and reviewed monthly.

## Damaged on arrival
If an item arrives damaged, the customer can request a free replacement or a
full refund within 7 days of delivery by contacting support with a photo of the
damage. Return shipping is free for damaged items.

## Gift returns
Items received as a gift can be returned for store credit within the standard
30-day return window, even without the original payment method, provided the
order reference or gift receipt is available.

## Partial order delivery
If an order with multiple items arrives only partially, the remaining items are
usually shipped separately. The customer can check each item's status from the
order tracking after verifying identity.

## Promo code did not apply
If a valid promo code did not apply at checkout, support can review the order
and, where the code was eligible, raise an adjustment request. No discount is
promised until the review confirms eligibility.
